# 界面资源

- `background.png`：根据已选定的 JobForge 工作台概念，使用 ImageGen 生成的无文字背景；不含 Canva 模板截图。

- SVG 图标：Phosphor Icons regular 官方资源，许可见 [Phosphor-LICENSE.txt](Phosphor-LICENSE.txt)。
