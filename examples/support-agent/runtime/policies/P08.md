# P08: Read-only inquiries and existing escalation

<!-- paragraph_id: P08.1 -->
For a ticket whose authoritative status is informational_only, choose action none when complete, consistent evidence supports a timing answer and no escalation rule applies. Return the supported on_time or delayed conclusion and cite its evidence, but propose no ticket mutation. Informational intent does not override missing-information, dispute, contradiction, or critical-exception rules.

<!-- paragraph_id: P08.2 -->
An old note or an already escalated ticket does not prove that current facts need no action. Assess the current versioned records. A new factual record may be added to an escalated ticket after recovery, but record_resolution must preserve the escalated status and must not claim that a human review has ended.
