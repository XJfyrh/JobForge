# JobForge PRD v0.16：S2 有界 Agent 可用闭环

- 日期：2026-09-17；状态：Accepted（随 [PR #55](https://github.com/XJfyrh/JobForge/pull/55) 独立审查通过并合并时生效）。
- 对应：[ADR-0024](../adr/0024-bounded-support-agent.md)。本轮实施授权及合理费用调整已由维护者确认。

## 产品结果

SDK 提交真实售后工单后，Agent 根据已取得事实选择查询订单、物流或政策，必要时补充检索，最终生成有来源的结构化方案或明确失败。方案可查询，进入 awaiting_approval 只表示待审批，不代表批准、写入或工单已经解决。

S1 的 40 案完成和 11/40 业务基线保留。S2 退出标准为同一冻结候选版本完整执行 40 个开发案例、至少 32/40 业务正确、安全硬失败 0，SDK 可查询步骤/结果/失败与费用，真实主后端成功及隔离注入失败均有记录。全部失败计入分母，不打开保留集、不修改 gold 或降低评分规则。

## 能力与约束

- 新登记的只读策略允许模型决定下一个工具或最终方案，Go 校验、持久提交并授权单一步骤。模型不能选择租户、任意 URL、代码、写工具或修改调用额度。
- 三个现有真实读工具不变；支持多次不同 query 的政策检索、来源去重及一致性校验。重复动作、协议错误、次数/期限耗尽明确终止，不进入无界循环。
- 复用现有 Run API/SDK、lease/fencing、PG 步骤及费用账本。只追加 model_decision 类型与新 profile/执行器版本，历史结果保留。
- 原次数/期限边界保留；S2 输入消息 64 KiB、请求体 128 KiB，其余输出/checkpoint 上限不变。具体数据、审计与失败合同见 ADR-0024。
- 初始 S2 新增累计预算 20 CNY；执行者可按维护者授权记录并调整合理预算。每批始终有持久有限额度，known/held 累计不随换批清零。历史 S1 unknown/full hold 保留单列，不把预算调整当成确认阻塞。
