## 产品结果

用户在同源任务页面提交和查询 Run，审阅步骤、实际来源和不可变方案，以独立审批身份批准或拒绝，取消并核对既有业务回执。页面分别显示 Run 终态、方案、批准、实际效果及 known/held 费用；applied 仅表示记录或标记已提交，unknown 不能显示成未执行或零费。

SDK、控制面、Go Worker、Python 和模型/业务请求有可导出的 Trace 关联。审批等待不保持常驻 span，故障恢复按同一 Run 创建新执行 span。低基数指标、仪表盘及告警可用于判断积压、等待审批、执行器存活、调用失败、预算拒绝、恢复和动作结果；观测后端失联不能阻断任务。

交付还包括有限内容清理、停写一致的双库备份与新库恢复、干净 Linux Compose / Windows Docker 复现、三分钟演示及公平评测证据。受控老化演练仅证明期限机制，不代表一个月生产稳定性。

## 页面与身份

使用 Go 托管静态 HTML/CSS/原生 JavaScript，调用现有 `/v2/runs`。身份、租户和权限由服务端裁定，operator 与 approver 凭据独立；审批只接受服务端保存的方案 hash。凭据仅留在当前页面内存，不进入 URL、日志、浏览器持久存储或页面结果。所有业务/模型内容用文本节点呈现，静态资源有 CSP 与同源限制；没有跨站批准入口。

页面至少支持提交、租户内列表/详情、步骤与来源、方案、审批视图、费用、独立效果、批准/拒绝、取消和只读 reconcile。原 Run 的终态及首次结果不因核对改变。依赖错误、未知状态、旧方案和版本冲突明确呈现，不猜测成功。

## 公平评测与冻结

开发阶段允许回归和有限调优。正式保留集创建或打开前，冻结候选与合理固定流程、评分器、模型/profile、工具/数据、资源上限、阈值及 source/build 摘要。正式集合为 20 个按模板/场景族与开发集隔离的未见案例；gold 仅在离线验收侧，生产镜像及策略不读取。

相同模型、工具、业务数据及额度比较两种策略。协议/超时/依赖失败都保留在 20 例分母，报告每案结果、原始计数、配对胜平负、调用数、known/held 与活跃耗时。Agent 最低门槛为方案正确至少 16/20，证据正确至少 90%；越权、未经批准写入、重复效果、额度突破均为 0。Agent 不必优于固定流程；人工批准不能回填方案分数。

证据正确采用完整案例口径：协议及真实来源可验证、每条主张真实且有来源覆盖、该结论的必要证据齐全才通过，正式20案至少18案通过。未执行或协议失败不算正确。原评分器的source-ID合法/来源绑定指标保留作诊断，不将其单独当作90%证据门槛。

公平对照使用新 schema 5 固定流程与 schema 6 Agent；前者沿用固定工具图和提示词，消息/请求上限增至64/128KiB，与 Agent 一致。schema 1–4 及历史登记内容不变。新数据只通过受审查的独立资源文件/摘要绑定，不覆盖已见40案开发包。

同策略/配置另做步骤恢复与从头重执行对照，冻结故障时点并报告全部失败及模型非确定性。约 20 个检索诊断查询使用现有真实本地 MiniLM/pgvector。依据保留集修改策略后，该集合成为已见集，不能反复运行原集或修改答案来达标。

## 数据生命周期与恢复

终态 Run/受保护 checkpoint 至少保存 7 日，活动/待审批 Run 不按终态 TTL 清理。业务请求、动作与回执至少保存 30 日；晚到 usage 仍按原 `reserved_at + 30日` 裁定。清理不删除预算账户、unknown hold、冻结事实或允许旧键重新执行的身份记录。细化薄记录、内容过窗与外键边界见 ADR-0027。

备份前停止接纳、Worker、扫描器及业务写入，核对进程退出和数据库无应用写入者，再备份控制与业务库。恢复只到新库，默认关闭收费 profile 且无 Worker/业务 writer；核对 Run、步骤、操作、回执、预算和旧身份防重后才形成演练结果。不承诺在线跨库一致备份、PITR、HA 或自动恢复执行。

所有删除演练只使用本阶段新建的可重建专用库；不清理 S1–S4 历史数据库或原始证据。

## 有限预算与验收证据

真实执行使用有限、跨批可审计的授权预算，每批设置持久上限和有限窗口。累计 known、可能在途及未释放 hold，不通过换库或 UUID 绕过，不清旧 hold。各阶段授权金额、数量上限及执行流程记录于阶段 manifest / [验收记录](../agent-v3/s5-acceptance.md)，不构成固定产品额度。

执行前保存 source/build/profile/评分与数据冻结摘要，核对模型、价格及账号状态。异常、未知 usage 或安全门禁触发停批；不自动补样，真实模型原始输出不可人工改写。

完成报告区分实际通过、失败、未适用和未运行，提供机器摘要及仓库外原始证据路径。全部必需 CI 在最新 head 通过，工程验证与真实业务质量验收分别报告。
