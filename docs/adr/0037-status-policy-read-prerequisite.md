# ADR-0037：特殊工单状态的政策读取前置条件

- 日期：2026-10-13；状态：Accepted（维护者要求分析原因后继续；`/root/s5_design_review` 独立接受设计方向，实现验证另记）。
- 增补 [ADR-0036](0036-s5-controlled-policy-supplement.md)。旧候选、停止批次与原始证据不变。

## 原因与选择

[v6 开发验证](../evidence/agent-v3-s5-v6-development-2026-10-13.md)中，DEV-031/033 的最终输入都有权威 `informational_only` 状态、允许的状态主张和 P08.1 补证入口。031 请求补证后正确，033 没有补证而直接提出记录结论。033 的时效判断正确，计量、容量和期限正常。已确认的缺陷是必要行动政策的发现仍依赖模型，不能由成功的补证执行机制保证；不推测模型内部动机。

新增 schema **15**、`support-agent-prompt-v7`、`linux-v2-adjudication-runtime-4`，继续使用 `support-agent-decision-v2`。在调查 marker 之后、首次 thinking 之前，Go 根据权威快照读取以下政策依赖：

| 权威工单状态 | 必需的实际政策段落 |
|---|---|
| `informational_only` | P08.1 |
| `escalated` | P08.2 |

其他状态不新增读取。只按枚举值路由，不读取描述关键词、初稿行动、gold 或评分谓词。已有来源绑定的必需段落则直接终裁；缺少时使用原 `ticket_status` 固定查询补读一次。选择 marker 边界，以保留现有调查导航和实际请求；不改成 `read_ticket` 后提前检索。

这是读取义务，不是行动规则。P08.1 的无动作条件及缺失信息、争议、冲突、严重异常例外仍由模型结合事实与实际政策判断。P08.2 不等于无动作，也不表示人工审查已经结束。仅取得段落不能证明最终答案正确。

独立核对开发 40 与三个已见 20 案包，特殊状态共 24/100：16 案 `informational_only`、8 案 `escalated`；其 gold 行动分别为 9 无动作、3 记录结论、10 升级、2 补信息。S5-010 是 `escalated` → `request_information / awaiting_information`，因此不能将 P08.2 扩成所有行动都保持状态。该统计仅用于离线确定覆盖范围，gold 不进入运行时。

## 执行、隔离与恢复

路径为 marker → 已满足前置条件或 Go 固定检索 → 首次 thinking → final 或原一次模型补证 → 独立 final。前置检索不消耗模型补证次数，但两者共用原每 Run 8 工具、12 chat、物理调用、费用和期限许可。两次 thinking 容量及 family token 上限沿用 schema 14，不增加阶段预算。

- Go 的 marker 提交、工具 admission、工具提交与终裁提交共同验证该路径；Python 只校验 Go 选择并执行登记单步。
- 若相同固定查询已执行却仍缺必需段落，不重复搜索。空结果、无关结果、缺目标段落或来源/快照不符都失败关闭，不发送首次 thinking。
- 前置读取后，同一状态查询不再进入模型补证目录；其他主题仍有一次补证机会。模型不能借此前置读取获得第二次可选补证或自由查询。
- 首次终裁输入只含累计已提交事实与政策，不含调查初稿、路由意图、预设行动或前次推理。第二次终裁继续 final-only。
- 复用现有持久步骤、工具计量、租约和幂等机制。恢复从已提交 marker/检索继续，不重发已提交读取；confirmed-uncommitted 与 unknown hold 仍按 ADR-0025。审批和动作写入不变，不新增 migration。

## 验证与收费边界

免费验证覆盖：全体已见特殊状态的影响范围；新旧版本隔离；段落已存在/缺失；重复查询、空/无关/跨快照结果；前置读取后可选补证、最终输入隔离；预算耗尽、取消、陈旧 lease 和恢复；Go/Python 共同向量；历史请求哈希与评分。状态图修改使用真实 PG、全仓 race 和固定 Linux 进程检查。

沿用原评分和质量门槛，marker 与最终输入闭合分别保留。免费验证与独立审查通过后，使用新身份与受审查的有限 manifest，从完整开发 40 案开始，不续跑 v6 剩余 7 案，不只重跑 033。每批 ¥4、S5 累计 ¥28 不变。当前 observed-usage 估算 ¥11.644792、held 为零；本决策不放行尚未审查的收费 manifest。
