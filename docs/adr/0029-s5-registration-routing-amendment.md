# ADR-0029：S5 正式登记路由的冻结后操作修订

- 日期：2026-10-08；状态：**Accepted，独立规划审查接受，随本 PR 合并生效**。
- 增补 [ADR-0028](0028-versioned-support-evidence-navigation.md) 的正式登记流程。

新候选已完成开发回归并冻结，新正式 v2 的 20 案已获独立审查。正式批次仍为零 Run、零模型调用时，官方登记工具将已允许的 v2 错路由到开发集的 40 案数量校验，返回 `CASE_COVERAGE`。

修复 `tools/support_evaluation/evidence.py` 的登记数量分支：`s5=True` 时正式 v1/v2 均为 20 案，开发集仍为 40 案。未知 dataset、错误数量和其他登记约束继续拒绝。沿用已审查案例及已通过开发回归；提示词、模型、工具、家庭额度、评分谓词、覆盖规则与 16/18 门槛保持原冻结值。已见诊断路径仍只接受正式 v1。

保留原冻结、原 manifest、原准备文件和零调用失败证据。另存一次操作修订凭证，链接原冻结及独立批准，记录实际 `amended_at`、新源码提交、源码差异和 operator 构建摘要。有效冻结明确引用原候选冻结与后续操作修订；原 `frozen_at` 表示未变候选与质量合同，后续提交时间单独记录，不宣称新提交早于案例创建。

生产 Worker、业务镜像及 Go 二进制复用原身份，只重建包含登记工具的 operator。新 manifest 只重绑有效冻结摘要，seed、政策、gold、anchors、两策略蓝图及模型参数保持。两策略真实 prepared 20 案通过官方登记、数量及未知 dataset 负例通过，修订绑定包获独立核验后，继续原 Agent 20 案再 Fixed 20 案授权。
