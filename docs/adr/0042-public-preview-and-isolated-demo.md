# ADR-0042：公开预览与隔离免费演示

- 日期：2026-10-16；状态：Accepted（维护者批准对外展示与接入方案）。
- 增补现行展示、打包与复现入口，不改变Run、审批、费用、模型质量或旧Job合同。

## 决策

免费hello run复用明确的integration target及真实控制/业务数据库、Go、固定Python进程和业务回执。模型响应、向量及费用保持显式模拟。演示入口只编译到测试镜像，生产registry、固定供应商origin和凭据隔离保持原样，不增加生产运行时mock开关。

Docker Desktop对仅内部网络的容器不发布宿主端口。演示执行器仅连接internal网络；独立Python标准库HTTP入口连接该网络及入口网络，只向固定后端转发一次HTTP，宿主仅发布loopback。入口没有模型密钥、写入签名或任意URL代理。UI标明模拟范围；会话90分钟后退出，正常停止按既有测试清理其专用库。

Python分发采用SPDX许可表达式和项目内许可正文；两份许可由根LICENSE生成并逐字节校验，构建后端最低使用支持PEP639的hatchling 1.27。包及镜像内容变化使用新摘要，不回写历史冻结回执。

OpenAPI补充连接与示例元数据，不修改请求/响应或SDK一次HTTP合同。生产SLO声明限定当前v3，不撤销旧Job合同。发布的质量数字绑定原V9冻结候选，不把新版UI或免费模拟改称新的实模验收。

## 验证与影响

验证包括实际wheel/sdist及从sdist重建、演示真实PG/进程与审批回执、身份/原方案绑定、原始契约和镜像隔离检查。演示源数据及生成回执属于专用环境，不能作为真实模型质量证据。平台与演示测量由[演示说明](../demo.md)记录。

本轮无数据库迁移，无新增收费调用，文档站和PyPI上传不在本次交付范围。发布附件只包含明确白名单和对应来源说明。
